# 에브리타임 시간표 가져오기

날짜: 2026-09-09  
상태: 검토 대기

## 목표

시간 찾기 약속방에서, 참여자가 에브리타임 시간표를 가져와 **수업과 겹치지 않는 칸**을 가능한 시간으로 자동 선택한다. 이후에도 드래그로 수정할 수 있다.

날짜만 찾기 방에는 넣지 않는다.

## 사용자 흐름

1. 참여자가 이름을 넣고 방에 들어온다.
2. **내 시간** 보기 위에 `에브리타임 가져오기` 버튼이 있다.
3. 하단 시트에서 공개 공유 링크를 붙인다. 형식이 아니거나 읽기 실패하면 시간표 캡처를 올린다.
4. 가져온 수업을 방의 후보 날짜 요일에 맞춘다. 수업과 겹치는 30분 칸은 빼고 나머지를 선택한다. 그날 수업이 없으면(주말 포함) 그날 칸은 전부 가능으로 둔다.
5. 선택 결과는 기존과 같이 바로 저장된다. 참여자는 그리드를 드래그해 더하거나 뺄 수 있다.
6. 가져오기에 실패해도 이미 고른 시간은 유지한다.

## 범위 밖

- 에브리타임 로그인, 친구 시간표, 학기 전체 캘린더 동기화
- 시간표 원본(링크, 이미지, 수업 목록)을 서버에 보관
- 방 만들기 화면, 날짜만 찾기 방
- 비전 API 키를 필수로 두는 것. 캡처는 보조 경로이며, 링크가 본 경로다.

## 구조

에브리타임 원본은 저장하지 않는다. 결과는 기존 `AvailabilitySlot`과 `saveAvailability`만 사용한다.

| 단위 | 역할 | 의존 |
| --- | --- | --- |
| `EverytimeImportSheet` | 내 시간에만 보이는 버튼과 하단 시트. 링크 또는 이미지 제출 | `importEverytime` |
| `importEverytime` | 링크/이미지를 수업 블록 목록으로 변환. `everytime.kr` 공개 페이지만 요청 | 파서 |
| `applyTimetableToSlots` | 수업 블록 + 방 날짜/시간 범위 → 가능한 슬롯 `Set` | `time-slots` |
| `RoomClient` | 가져온 `Set`을 `handleSelectionChange`에 넘겨 저장 | 위 세 단위 |

데이터 흐름:

```
링크 또는 캡처
  → importEverytime → ClassBlock[]
  → applyTimetableToSlots(room.dates, timeStart, timeEnd, blocks)
  → handleSelectionChange(freeSlots)
  → saveAvailability
```

`ClassBlock`은 `{ weekday: 0–6, start: "HH:MM", end: "HH:MM" }`이다. `weekday`는 JS `Date.getDay()`와 같다(0=일). 수업 이름은 파싱되면 버려도 된다. 저장하지 않는다.

캡처 파일은 요청이 끝나면 버린다.

## 링크 가져오기

허용 형식은 `https://everytime.kr/@{id}`와 `http`/`www` 변형이다. 다른 호스트는 거절한다.

서버는 사용자가 붙인 그 공개 페이지만 GET 한다. 타임아웃은 8초. 로그인 쿠키를 쓰지 않는다.

페이지에서 요일 열과 수업 블록(위치·높이 또는 동등한 마크업)을 읽어 `ClassBlock[]`을 만든다. 블록이 비어 있으면 실패로 보고 캡처를 안내한다.

## 캡처 가져오기

공개 링크가 아니거나 페이지를 못 읽으면 시트가 캡처 업로드를 연다.

이미지도 같은 `ClassBlock[]`으로 맞춘다. 격자·색 블록처럼 확신할 수 있는 신호만 쓰고, 없으면 실패한다. 추측으로 칸을 채우지 않는다. 비전 API는 쓰지 않는다.

허용 유형은 이미지(jpeg, png, webp, heic). 최대 8MB.

## 슬롯 변환

방의 각 `date_candidates`에 대해 요일을 구한다. 그 요일의 수업과 30분 칸 `[slot, slot+30분)`이 겹치면 불가능한 칸이다.

겹침: `classStart < slotEnd && classEnd > slotStart`.

가능한 칸 = 방의 모든 `(date, slot)` 가운데 불가능한 칸을 뺀 것.

이미 선택돼 있던 칸은 가져오기가 성공하면 **통째로 덮어쓴다**. 실패하면 그대로 둔다.

## 실패 메시지

| 상황 | 메시지 | 기존 선택 |
| --- | --- | --- |
| 링크 형식이 아님 | 공개 공유 링크를 붙여주세요 | 유지 |
| 비공개이거나 페이지를 못 읽음 | 시간표 캡처를 올려주세요 | 유지 |
| 캡처에서 수업을 못 찾음 | 다시 올리거나 칸을 직접 골라주세요 | 유지 |
| 시간 초과/네트워크 | 다시 시도하거나 캡처를 올려주세요 | 유지 |

오류는 시트 안에서만 보여 준다.

## 확인

단위:

- 월 10:00–11:30 수업 → 해당 요일 날짜의 10:00, 10:30, 11:00만 제외
- 수업 없는 일요일 → 그날 전부 가능
- 수업이 칸과 1분이라도 겹치면 그 칸은 제외
- 잘못된 URL / 빈 블록은 선택을 바꾸지 않음

브라우저:

- 내 시간에만 버튼이 보인다. 그룹 보기, 날짜만 방, 입장 전에는 없다.
- 링크 실패 후 캡처로 이어진다.
- 가져온 뒤 드래그 수정이 저장된다.

## 공개 범위

링크 가져오기는 에브리타임에서 **URL 공유로 공개한 시간표**만 된다. 시트에 한 줄로 안내한다.
